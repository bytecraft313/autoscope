# AutoScope

**AutoScope** is an open-source Python-based OBD-II vehicle diagnostics and data analysis project.

The goal is to connect a vehicle to a computer through an OBD-II adapter, collect real-time vehicle data, and provide useful diagnostics, logging, visualization, and analysis tools.

## Planned Features

* OBD-II vehicle connection
* Live sensor/PID monitoring
* Diagnostic trouble code (DTC) reading
* Vehicle data logging
* Trip recording and analysis
* Interactive dashboards
* Historical data visualization
* Custom alerts and diagnostics
* AI-assisted vehicle analysis *(future)*

## Tech Stack

* Python
* python-OBD
* Streamlit
* SQLite
* Plotly

## Project Status

**Early development**

The project is initially being developed and tested with a **2008 Toyota 4Runner** and will gradually evolve into a more general-purpose OBD-II diagnostic platform.

## Disclaimer

AutoScope is an experimental diagnostic and data-analysis tool. Always verify important diagnostic findings using appropriate professional equipment and service documentation.
